# HumanoidBehavior — Robot Behavior Evaluation

A lightweight discovery/demo Space for **HumanoidBehavior**, an early-stage robotics behavior and evaluation infrastructure asset.

The live product provides versioned behavior specifications, browser-first measured MuJoCo execution, reproducible experiments, replay, and persisted reports.

> **Important:** this Space is a discovery interface. It does **not** claim that the Space itself has executed or measured a robotics benchmark.
