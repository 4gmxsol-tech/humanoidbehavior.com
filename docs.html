QUICKSTART

Run your first benchmark

Create an API key in Workspace, then call the benchmark endpoint.

curl -X POST https://your-domain.example/api/benchmark \
  -H "Authorization: Bearer hb_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"behaviorId":"pick-place","completedSteps":["Perceive target object","Navigate to workspace","Reach and grasp","Transport object","Release at target","Verify placement"],"model":"my-policy"}'

Response

{
  "status": "passed",
  "behaviorId": "pick-place",
  "adapter": "spec-validator"
}
