Privacy

This page describes the categories of information the HumanoidBehavior service may process when you use the website and workspace.

Information we may process

  • Account information such as email address and authentication/session records.
  • Workspace data such as behavior, experiment, run, seed, policy and artifact metadata you submit or generate.
  • API key metadata and usage information needed to operate authenticated API access.
  • Technical information required for security, reliability and abuse prevention, such as request metadata and service logs.

How information is used

Information may be used to authenticate users, provide experiments and reports, persist workspace data, enforce usage limits, maintain security, troubleshoot failures and improve the service.

Public reports

If you explicitly create a public experiment share link, the information exposed by that report may be accessible to anyone with the link. Do not publish confidential or personal information in public experiment metadata.

Service providers

The current architecture uses GitHub Pages for the frontend and Cloudflare services for the application/API and durable data layer. Third-party services may process information according to their own terms and privacy policies.

Data retention and deletion

Retention depends on the account, workspace and service configuration. Requests concerning account or workspace data can be directed through the contact page.

Security

We use measures such as HTTPS transport, password hashing, authenticated sessions, revocable API keys and server-side authorization controls. No internet service can guarantee absolute security.

Changes

This privacy information may be updated as the product and its data practices evolve. The current version is published on this page.
