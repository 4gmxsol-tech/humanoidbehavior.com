06 · TRANSACTION SCOPE

A clean asset boundary.

Core assets

  • HumanoidBehavior.com domain.
  • Repository/source-code access as agreed.
  • Frontend, application and product assets.
  • Worker/D1 architecture and deployment configuration.
  • Documentation, brand/content and handoff materials as agreed.

Explicitly subject to agreement

  • Registrar, GitHub and Cloudflare account transfer structure.
  • Third-party service accounts.
  • Credentials and secrets, transferred securely and rotated.
  • Datasets, analytics and experiment records.
  • Any separately assigned intellectual-property rights.

The repository currently uses the MIT License. Any transaction must distinguish the domain/brand, existing open-source source code, proprietary configuration/data/accounts and any rights expressly assigned by agreement. The source should not be represented as exclusively owned if its existing license does not provide that exclusivity.
